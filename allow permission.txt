============================================================
OFFLINE SCHOOL WEBSITE — LOCAL SERVER TROUBLESHOOTING
============================================================

IMPORTANT:
- Do NOT close CMD after a server successfully starts.
- A successful server normally stays on the screen.
- If CMD immediately returns to C:\...>, move to the next step.
- In Edge, use http://127.0.0.1:PORT or http://localhost:PORT
- Do NOT change Windows proxy settings.

------------------------------------------------------------
1. CHECK PYTHON
------------------------------------------------------------

Run:

python --version

If a Python version appears:
→ Go to Step 2.

If it says Python is not recognized:
→ Go to Step 3.


------------------------------------------------------------
2. START SERVER NORMALLY
------------------------------------------------------------

Run:

python -m http.server 8000

If CMD stays open and shows something like:
"Serving HTTP on..."

→ SUCCESS.
Open Edge:
http://127.0.0.1:8000

If CMD immediately returns to the prompt:
→ Step 4.


------------------------------------------------------------
3. TRY PY LAUNCHER
------------------------------------------------------------

py --version

If it stays running:
→ SUCCESS.
Open:
http://127.0.0.1:8000

Otherwise:
→ Step 4.

→ Step 5.

------------------------------------------------------------
29. CHECK WHETHER PYTHON COMMAND IS ACTUALLY EXITING
------------------------------------------------------------

Run:

python -m http.server 8000

Immediately after it returns to the prompt, run:

echo %errorlevel%

If it shows:

0

the command exited without a reported error.

If it shows another number:
→ Python reported an error condition.

Then try:

py -m http.server 8000

If successful:
→ DONE.

Otherwise:
→ Step 30.

------------------------------------------------------------

Run ALL of this:

cd /d "YOUR WEBSITE FOLDER"

py -m http.server 49152 --bind 127.0.0.1

If CMD stays running and shows that it is serving HTTP:

Open Edge:

http://127.0.0.1:49152

If that works:
→ WEBSITE SERVER IS RUNNING.

If CMD STILL IMMEDIATELY RETURNS to the prompt:
→ The school computer's Python installation/environment is
   the problem, not your website.
